Verify a download

Every file is listed in SHA256SUMS.txt, which is signed with the Clotho release key (clotho-update.pub). With minisign installed:

minisign -Vm SHA256SUMS.txt -p clotho-update.pub
sha256sum --check --ignore-missing SHA256SUMS.txt
